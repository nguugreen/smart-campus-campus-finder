## ชื่อระบบ หัวข้อ และกลุ่มที่

- **ชื่อระบบ:** Campus Finder
- **หัวข้อ:** โจทย์ของกลุ่มที่ 1 Campus Finder (Smart Campus)
- **กลุ่มที่:** 1 (กลุ่มบุ้น)
- **สถานการณ์ปัญหา:** นักศึกษาใหม่ ผู้ปกครอง และบุคคลภายนอกมักหาอาคารหรือห้องเรียนไม่เจอ เช่น ไม่รู้ว่าห้อง 6121 อยู่อาคารไหน ชั้นไหน หรือไม่รู้ว่าจุดถ่ายเอกสาร ห้องพยาบาลอยู่ตรงไหนและเปิดกี่โมง
- **วิธีแก้:** เว็บที่รวมข้อมูลสถานที่จริงในมหาวิทยาลัย ให้ค้นหาได้รวดเร็วจากมือถือ
- **ผู้ใช้เป้าหมาย:** นักศึกษาชั้นปีที่ 1, ผู้ปกครอง, บุคคลภายนอกที่มาติดต่อ

## รายการฟีเจอร์

### ฟีเจอร์หลัก (F1–F6 ทำครบ)

| รหัส | ฟีเจอร์ | รายละเอียด | สถานะ |
|---|---|---|---|
| F1 | แสดงรายการสถานที่ | ดึงข้อมูลจาก `data/places.json` ด้วย fetch แล้วสร้างการ์ดด้วย DOM | ทำแล้ว |
| F2 | ค้นหาแบบ real-time | ค้นหาจากชื่อหรือรหัสสถานที่ ไม่สนตัวพิมพ์เล็ก/ใหญ่ | ทำแล้ว |
| F3 | กรองข้อมูล | กรองตามประเภท (type) และโซน (zone) ใช้ร่วมกับการค้นหาได้ | ทำแล้ว |
| F4 | เวลาเปิด-ปิด | แสดงเวลาและสถานะ เปิด/ปิด ตามเวลาปัจจุบัน | ทำแล้ว |
| F5 | รายการโปรด | บันทึกลง `localStorage` ดูและลบได้ในหน้า Favorites | ทำแล้ว |
| F6 | ฟอร์มเสนอแนะ/แจ้งข้อมูลผิด | มี validation เก็บใน `localStorage` และแสดงข้อความยืนยัน | ทำแล้ว |

### ฟีเจอร์เสริมที่ทำ
